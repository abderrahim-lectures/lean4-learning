## v1.5.0 — Major LaTeX restructuring: removed "The story of this chapter" section heading; removed "Sections" section entirely

This release restructures the LaTeX manuscript output to match a cleaner book layout. The changes are purely presentational (Markdown source is unchanged).

### LaTeX output changes

**Removed `\section{The story of this chapter}` heading from every chapter driver (`00-index.tex`).** The narrative intro text (the "story" paragraphs and the numbered section-list) now flows directly under the `\chapter{}` title, without an intermediate section heading. This eliminates the redundant "The story of this chapter" label while keeping all the narrative content intact.

**Removed the entire `\section{Sections}` section (heading + body) from every chapter driver.** The numbered TOC that previously appeared under a "Sections" heading is now gone. The story text already contains a natural-language section list with hyperlinked cross-references, making the separate enumerate redundant.

### Files affected

- `lean_book/build/build_latex.py` — new `strip_story_and_sections_headings()` post-processing function applied to all chapter `00-index.tex` files.
- `lean_book_latex/*/00-index.tex` — all 14 chapter drivers regenerated.

### Version bump

Book version updated from `v1.4.25` to `v1.5.0` in `lean_book_latex/preamble.tex` (`\bookversion`).

### Notes

- The Markdown source (`lean_book/*/00-index.md`) is **unchanged** — it still uses `## The story of this chapter` and `## Sections` headings. The LaTeX-only transformation happens in the build pipeline.
- All cross-references (`\hyperref` links in the story text's enumerate) remain functional.
- The generated PDF is 276 pages.
