## v2.0.7 — Antithesis-drumbeat and front-matter prose pass

### What changed

- **Antithesis-drumbeat pass, whole book.** Swept every chapter for the
  two-sentence "X is not Y. It is Z." pattern (a rhetorical habit that
  reads fine sentence by sentence but pushes the reader once it repeats
  across a section). Rewrote every genuine instance found, 9 across
  `01-basics`, `02-terminology-and-coc`, `03-functions-and-structures`,
  `04-propositions-and-proofs`, `06-rigor-check`, `09-rings`, and
  `13-working-efficiently`, to state the positive claim directly. One
  dictionary-vocabulary swap (`tractable` → `workable` in
  `10-ring-theorems/01-setup.md`).
- **Front/back matter prose pass.** `lean_book_latex/frontmatter.tex`
  and `lean_book_latex/backmatter.tex` sit outside the Markdown → LaTeX
  pipeline and had never been swept against this book's own prose
  conventions. Fixed 15 em-dashes used as sentence punctuation, 3
  possessives (`quiver's`, `Mathlib's`, `Group's`), 4 colon-led
  explanations, and a rhetorical-question list in "How to read this
  book" ("already know Lean? already know algebra?..."), all rewritten
  as plain sentences per CONTRIBUTING.md's "Book prose conventions."
- **Stale toolchain reference fixed.** `backmatter.tex` stated
  `v4.31.0`; the pinned toolchain (`lean_project/lean-toolchain`) and
  the rest of the book have read `v4.33.1` since v2.0.5.
- **New skill: `plain-prose-repair`.** Ported from the author's
  `research-ideas` repository and retargeted at this book's Markdown
  chapters, driven by `tools/scripts/check-plain-prose.sh`. Detects the
  antithesis-drumbeat pattern and precise-but-uncommon vocabulary by
  count, since both are frequency defects invisible to a sentence-by-
  sentence read. Companion to the existing `prose-style-reviewer` skill.
- **Removed stale scratch files.** `NEXT_AGENT_TODO.md` and
  `AGENT_HANDOFF.md` were leftover session state from an abandoned
  2026-08-02 review branch (`docs/v1.5.0-lean-update-and-reviews`,
  referencing the superseded `v4.32.2` toolchain and a review pipeline
  that never merged). Removed as clutter; the actual review record
  lives in `reviews/` and this changelog.

### Release changes

- **Version bump.** `\bookversion` in `lean_book_latex/preamble.tex`
  advanced to `v2.0.7`.
- **PDF rebuilt.** The release PDF was regenerated through the LaTeX
  pipeline and attached to this release.
- **README updated.** PDF download links point at the `v2.0.7` asset
  name.
