## v1.4.24 — Full-book rigor audit, plus a narrative rewrite of Chapter 1

**Rigor audit** (4 parallel passes, one per chapter group, each
cross-checking every Lean snippet against the toolchain pinned in this
repository's `lean_project/lean-toolchain`):

- `01-basics/01-everything-has-a-type.md`: `#check 3 + true`'s claimed
  error was `failed to synthesize Add Nat Bool`; actual is
  `HAdd Nat Bool ?m` (heterogeneous `HAdd`, not `Add`).
- `01-basics/03-dependent-types.md`, `01-basics/05-pi-sigma-and-coc.md`:
  `#print Fin` claimed `Fin.isLt : val < n`; actual is `Fin.isLt : ↑self
  < n`, in both places this output is shown. Also fixed a missing paren
  in a `Vec.replicate` `#eval` output and the pretty-printed form of a
  `Vec.head Vec.nil` error (`Vec.nil.head`, not `Vec.head Vec.nil`).
- `02-functions-and-structures/02-type-parameters.md`: an internal
  inconsistency — the file said `structure Group (α : Type)` where every
  other use in the book (and the actual Lean source) writes
  `Group (G : Type)`.
- `03-propositions-and-proofs/02-logic-recap.md`: aligned a "1929" vs.
  "1929/1930" date inconsistency for Gödel's completeness result.
- `03-propositions-and-proofs/08-exercises.md`: a Socratic question
  referenced an unproved claim (`∃ n, n > 0`) as though already proved;
  corrected to the example actually proved via `by decide`
  (`exists_prime_gt_three`).
- `04-tactics/01-goal-state.md`, `04-tactics/03-reading-failures.md`: two
  wrong quoted Lean error messages, corrected against real `lake env
  lean` output; also separated two error messages ("motive is not type
  correct" vs. "did not find instance of the pattern") that had been
  incorrectly attributed to the same cause.
- `05-rigor-check/02-universes.md`: removed a fabricated exception clause
  in the stated Π-type universe-formation rule that didn't match Lean's
  actual behavior or the book's own "precise" restatement of the same
  rule elsewhere in the same file.
- Chapters 6–9 and 10–14 (23 files, including all appendix solutions):
  audited in full, no defects found — every `#eval`/`#check` output,
  worked example, and cross-reference checked out against the actual
  Lean source.

**Chapter 1 narrative rewrite.** Reader feedback: individual paragraphs
were thorough but the chapter read like reference cards rather than a
book — no throughline connecting why each section follows the last.
Fixed by:

- Adding a genuine story arc to `01-basics/00-index.md`: each section is
  now framed as the answer to a question forced by the previous
  section's answer, stated up front before the details.
- Moving every section's "Recall" box (bolded term → verbatim quote →
  citation) from the top of the section — the reader's first impression,
  before any narrative — to the bottom, as a recap after the story has
  been told, matching how a reader actually wants to encounter a new
  idea.
- Adding connective transition paragraphs between sections 1→2→3 and at
  the top of the terminology section, explaining why each new concept is
  needed now rather than introducing it cold.

**Also:** a local `notebook-cache/` (gitignored) was introduced to cache
NotebookLM citation-verification queries and their responses, and
already-verified quotes from the book's Recall sections, so future
sessions don't re-ask questions already on record — including the
ongoing NotebookLM outage diagnosis (four distinct failure modes
observed, pointing to an upstream/scraper issue rather than quota or
auth). The Dummit & Foote group-axiom quote in
`06-groups/01-definition.md`'s Recall section remains a paraphrase,
not yet a verbatim quote, pending that tool's recovery.

All Lean snippets touched were verified directly against the toolchain
pinned in this repository's `lean_project/lean-toolchain`; no `.lean`
source files were modified, only prose corrected to match verified Lean
behavior.

**Repo layout:** moved the generated LaTeX tree from `lean_book/latex/`
to a top-level sibling directory, `lean_book_latex/`, for a cleaner
separation between hand-written Markdown source (`lean_book/`) and
generated build output. Updated `build/build_latex.py`'s path
construction accordingly (including the two hardcoded cover-image paths
and the per-chapter `\includegraphics` path fixup, both of which assumed
the old nested location), moved the LaTeX-artifact `.gitignore` rules
into a new `lean_book_latex/.gitignore`, and updated `CONTRIBUTING.md`'s
one reference to the old path. Rebuilt the PDF end to end
(`build/build_latex.py` → `xelatex` → `biber` → `xelatex` ×2) from the
new location to confirm the pipeline still produces the same 276-page,
warning-free output. Also added a missing `references.bib` entry for
`FeysLadriere1955` (present in `bibliography.md` since the Gentzen
citation fix above, but never added to the separate LaTeX bibliography
database), which `biber` was silently unable to resolve until now.
