\section{Chapter 8: Group examples and basic theorems}\label{sec:15-appendix-solutions:08-chapter-8:1}

\textbf{1. Could \texttt{id\_\allowbreak{}unique} route through \texttt{Grp.op Grp.id e'} instead?}

Not directly. \texttt{h} is the hypothesis that \texttt{e'} is a \emph{left} identity, so it only describes \texttt{Grp.op e' a} for arbitrary \texttt{a}; it says nothing about \texttt{Grp.op a e'}. The proof of \texttt{id\_\allowbreak{}unique} has to route through the one expression, \texttt{Grp.op e' Grp.id}, that both given facts (\texttt{h} and \texttt{Grp.id\_\allowbreak{}right}) actually describe, not any expression that happens to mention both sides.

\textbf{2. Can \texttt{inv (a op b)} be computed directly from the axioms?}

Not from the axioms alone. \texttt{Group} has no field that produces \texttt{inv} of a \emph{product} in closed form, only \texttt{inv} of a single element. Reducing ``compute this'' to ``verify this satisfies the defining property'' of Theorem 2 is not a shortcut taken for convenience; it is the only route the axioms actually offer, which is exactly why \texttt{inv\_\allowbreak{}op} is proved by characterization rather than direct computation.

\textbf{3. \texttt{theorem inv\_\allowbreak{}inv (a : G) : Grp.inv (Grp.inv a) = a}}

\begin{lstlisting}
theorem inv_inv (a : G) : Grp.inv (Grp.inv a) = a := by
  apply Eq.symm
  apply left_inverse_unique Grp (Grp.inv a) a
  -- Goal: op a (inv a) = id
  exact Grp.inv_right a
\end{lstlisting}

By \texttt{left\_\allowbreak{}inverse\_\allowbreak{}unique} (Chapter 8, Theorem 2), to show \texttt{a = Grp.inv (Grp.inv a)} it suffices to show \texttt{a} is a left inverse of \texttt{Grp.inv a}, i.e.~\texttt{Grp.op a (Grp.inv a) = Grp.id}, exactly \texttt{Grp.inv\_\allowbreak{}right a}.

\textbf{4. \texttt{theorem cancel\_\allowbreak{}left (a b c : G) (h : Grp.op a b = Grp.op a c) : b = c}}

\begin{lstlisting}
theorem cancel_left (a b c : G) (h : Grp.op a b = Grp.op a c) : b = c := by
  have h1 : Grp.op (Grp.inv a) (Grp.op a b) = Grp.op (Grp.inv a) (Grp.op a c) := by
    rw [h]
  rw [(*$\leftarrow$*) Grp.assoc (Grp.inv a) a b] at h1
  -- h1 : op (op (inv a) a) b = op (inv a) (op a c)
  rw [(*$\leftarrow$*) Grp.assoc (Grp.inv a) a c] at h1
  -- h1 : op (op (inv a) a) b = op (op (inv a) a) c
  rw [Grp.inv_left] at h1
  -- h1 : op id b = op id c
  rw [Grp.id_left, Grp.id_left] at h1
  -- h1 : b = c
  exact h1
\end{lstlisting}

Both sides of \texttt{h} are left-multiplied by \texttt{Grp.inv a} (step \texttt{h1}), then regrouped with associativity so that \texttt{Grp.inv a} meets \texttt{a} on both sides. That pair cancels to \texttt{Grp.id} via \texttt{inv\_\allowbreak{}left}, and \texttt{Grp.id} is then stripped via \texttt{id\_\allowbreak{}left}, which leaves \texttt{b = c} directly.
