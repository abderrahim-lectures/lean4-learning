\section{What forces the definition}\label{sec:07-groups:00-index:2}

The checkpoint project of Chapter 6 built a \texttt{Monoid}: an associative operation with a two-sided identity, no inverses. One question drives this chapter: what is the weakest extra condition that makes every element undoable? Requiring an inverse function \((-)^{-1}\) with \(a \cdot a^{-1} =
a^{-1} \cdot a = e\) is the smallest addition that does this, and it is exactly what a \textbf{group} is (\hyperref[sec:07-groups:01-definition:1]{Section 1}).

A definition earns its keep only if it is realizable in Lean and non-vacuous. Realizing it means specifying the recipe: bundle the raw signature \texttt{GroupData} first, then add one proof field per axiom to get \texttt{Group} (\hyperref[sec:07-groups:02-translating:1]{Section 2}). Non-vacuous means exhibiting an inhabitant: \((\mathbb{Z}, +, 0, -)\) satisfies all five axioms, citing one core-library lemma per axiom (\hyperref[sec:07-groups:03-integers-example:1]{Section 3}).

\texttt{intGroup} is commutative, so it cannot tell \texttt{id\_\allowbreak{}left} apart from \texttt{id\_\allowbreak{}right}, or \texttt{inv\_\allowbreak{}left} from \texttt{inv\_\allowbreak{}right} --- in an abelian group these coincide. Whether the left/right split in the definition is doing real work, rather than overcaution, can only be settled by a genuinely non-abelian example: the permutations of a 3-element set, built the same way, field by field, with both directions checked honestly (\hyperref[sec:07-groups:04-permutations-example:1]{Section 4}). They are not interchangeable there.

With two concrete groups built, their data is used exactly as any \texttt{structure}'s fields are used since Chapter 3, by projection, whether the field holds data or a proof (\hyperref[sec:07-groups:05-accessing-fields:1]{Section 5}). The return on building \texttt{Group G} generically, rather than writing \texttt{intGroup} and \texttt{perm3Group} as unrelated one-off definitions, is that a theorem proved once about an arbitrary \texttt{Group G} applies to both without further work (\hyperref[sec:07-groups:06-why-bundle:1]{Section 6}); Chapter 8 carries this out.
