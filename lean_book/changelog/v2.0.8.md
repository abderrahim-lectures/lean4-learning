## v2.0.8 — Inline citations, proof comparison blocks, and editorial pass 7

### What changed

- **Inline citations added to every Definition block and theorem statement.**
  Formal definitions, theorems, and named concepts now carry an inline
  citation `[Author Year, p.XX]` immediately after the block, not only in
  the "Sources, quoted" box at the bottom of each section. This ensures a
  reader encountering the term for the first time sees the source without
  scrolling to the end of the section. (~120 citations added across all
  chapters.)

- **`**Definition.**` blocks for every bolded term.** Approximately 30
  bolded technical terms across all chapters that previously lacked a
  formal `**Definition.**` block now have one. No bolded term appears
  without a corresponding formal stamp.

- **Side-by-side proof comparison blocks.** Key chapters now include
  comparison blocks showing an informal mathematical proof (1-3 sentences)
  next to the Lean formalization with inline tactic-level comments. These
  blocks build the mental bridge between "how I think about this proof" and
  "how Lean needs to see it."

- **Tactic-level Lean code documentation.** All previously undocumented
  code blocks now have inline comments explaining each tactic step, so
  readers can follow the proof strategy without guessing.

- **Circular definitions fixed in Chapter 5.** A circular reference in
  the tactic chapter was broken by reordering the relevant subsections.

- **Parenthetical glosses for early-use terms.** Terms that appear before
  their formal definition now carry a brief parenthetical gloss at first
  use.

### Documentation updates

- **`README.md`:** Pedagogical approach section updated with citation
  convention; new "Proof comparison blocks" section added after "How to
  read this book"; editorial passes section updated with seventh-pass
  description.
- **`CONTRIBUTING.md`:** New "Citation convention" and "Side-by-side proof
  comparisons" subsections under "Book prose conventions."
- **`proof-strategy-guide.md`:** New "Informal/formal proof comparisons"
  section explaining how to read the side-by-side blocks.
- **`00-setup/00-index.md`:** New "Conventions" section documenting the
  inline citation pattern.
