## v2.0.8 — Section-numbering fix, stale cross-references, and a motivation update

### What changed

- **Chapter-intro heading no longer eats a numbered section slot.**
  `lean_book_latex/build/build_latex.py`'s `strip_story_and_sections_headings()`
  matched the chapter-intro heading by literal title text
  (`"The story of this chapter"`), a title removed book-wide back in
  v1.5.0 and since replaced per-chapter (`"What forces the chapter"`,
  `"What forces the setup"`, `` "What forces `structure`" ``, etc.). The
  regex silently stopped matching years ago, so the intro kept its own
  numbered `\section`, and every real section after it in that chapter
  rendered one number higher than the "Section N" prose inside the
  intro claimed. Fixed by matching the intro heading positionally (the
  first `\section` left in the file after Learning Objectives is
  extracted) instead of by literal text, using brace-counted parsing so
  it survives titles with nested groups. Affected 9 chapters:
  `00-setup`, `01-basics`, `02-terminology-and-coc`,
  `03-functions-and-structures`, `04-propositions-and-proofs`,
  `05-tactics`, `07-groups`, `11-modules`, `12-path-algebras`.
- **Stray duplicate appendix-solutions files removed.** 9 leftover
  `.tex` files in `lean_book_latex/15-appendix-solutions/` from a past
  renumbering (e.g. `05-chapter-6.tex` sitting next to the current
  `06-chapter-6.tex`) were never `\input` by `00-index.tex` and did not
  affect the PDF, but cluttered the directory. Deleted.
- **Chapter 5 section-count drift.** `05-tactics/01-goal-state.md` had
  two `##` headings, rendering as two numbered sections where the
  chapter's own "Sections" list expected one section with a subsection.
  Demoted the second heading to `###`, fixing the "Section 2"..."Section
  5" shift that followed it.
- **Stale cross-reference.** `04-propositions-and-proofs/02-logic-recap.md`
  called the same link target "Chapter 2, Section 2" in one place and
  "Chapter 1, Section 5" in another. Fixed to match.
- **Citation title fix.** `bibliography.md` listed Aluffi's book as
  *Algebra: Chapter 1*; corrected to its actual title, *Algebra: Chapter
  0* (GSM vol. 104), matching `references.bib`, which already had it
  right.
- **New "Why Lean?" motivation content.** Added a paragraph on Lean's
  current reach: Anthropic's complete Lean-formalized proof of Fermat's
  Last Theorem (`[AnthropicFLT2026]`), Buckmaster and Alpöge's
  Lean-formalized finite-time blowup results for equations related to
  Navier–Stokes (`[BuckmasterAlpoge2026]`, careful to note Navier–Stokes
  itself remains open), and the Tau Ceti project
  (`[TauCeti2026]`). Also credited Lean's creator, Leonardo de Moura,
  and Sebastian Ullrich for the Lean 4 system description
  (`[DeMouraUllrich2021]`), and named the Lean Prover Community, the
  Lean Zulip chat, and Mathlib. 4 new bibliography entries, kept in sync
  between `bibliography.md` and `references.bib` (39/39 keys match).
- **Full book-wide numbering audit.** Verified every `\hyperref[...]{Section
  N}` mention in the book against the actual rendered `\thesection`
  (via the compiled `.aux` file): 0 mismatches remain.

### Release changes

- **Version bump.** `\bookversion` in `lean_book_latex/preamble.tex`
  advanced to `v2.0.8`.
- **PDF rebuilt.** The release PDF was regenerated through the LaTeX
  pipeline and attached to this release.
- **README updated.** PDF download links point at the `v2.0.8` asset
  name.
