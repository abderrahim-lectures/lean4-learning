## v2.0.9 — Deep word-by-word review, skill ecosystem wiring, and section-numbering fix

### What changed

- **Deep word-by-word review of all 15 chapters.** Every file read by
  six parallel review agents covering chapters 0–15 and the appendix.
  ~170 issues found and fixed across the entire book.

- **Antithesis drumbeat removal.** 10 instances of the banned pattern
  "It is not X. It is Y." rewritten as direct positive claims across
  chapters 00-setup through 02-terminology.

- **Defensive disclaimer cleanup.** "merely", "not intended to",
  "none of this is meant to suggest" removed or replaced with direct
  statements.

- **Grammar fixes.** Comma splices, run-on sentences, missing subjects,
  broken parentheticals, and duplicated content fixed across chapters
  01-basics, 04-propositions, 05-tactics, 06-rigor-check, 09-rings,
  11-modules, 12-path-algebras, and 14-next-steps.

- **Factual corrections.** "cancellation" → "inverses" in Chapter 7
  definition; `.ToPoint` → `.toPoint` capitalization fix; Python type
  annotation corrected in Chapter 6; duplicate `sorry` definition
  removed from Chapter 5.

- **Citation improvements.** Structure eta definition in Chapter 6
  now cites [TPIL4]; Schiffler citation in Chapter 12 now references
  specific definition number; forward references phrased as "as will
  be defined" instead of "Recall from Chapter N".

- **Meta-commentary removed.** Three parentheticals about "an earlier
  draft" embedded in running text deleted; drafting notes cleaned up.

- **Professional writing pass.** "obvious" → "standard"; "reassurance"
  → "confirms"; "beats it" → formal register; "all the way back in
  Chapter 1" → "from Chapter 1"; "smallest/most general" → "universal
  (initial)"; "its own quivers of this book" → "quivers from this book".

- **Section numbering fix.** `build_latex.py`'s
  `unnumber_intro_sections()` now correctly finds its cutoff marker
  (the `\section{Sections}` heading) instead of looking for
  `\input{...}` lines that don't exist when the function runs. All
  intro sections across 15 chapters now produce `\section*{...}`
  (unnumbered), so content sections start at 1.1, 2.1, etc.

- **`mathreading` box regex broadened.** The regex now matches
  `**Mathematical reading (optional, ...).**` in addition to
  `**Mathematical reading.**`, so the categorical reading box in
  Chapter 1 is correctly wrapped in the colored environment.

- **lean-ponytail v1.1.0.** Wired the full formalization pipeline:
  freshness gate (Gate 0), submodule search paths (lean/Research,
  .lake, vendor/*), registry skills (formal-math-ecosystem,
  palomar-registry, tauceti-contribution), GitHub logging
  (github-tracker, research-ledger). Non-duplication check run
  against formalization-strategy, lean-probe-first,
  lean4-explicit-proofs, third-party-freshness, formal-math-ecosystem,
  github-tracker, and research-ledger.

- **Skill ecosystem fixes.** `vendor/con-che` typo → `vendor/con-leche`
  in formalization-strategy; `security-reviewer` phantom reference →
  `security-review` in second-brain; `lean-lsp-mcp` → `lean-beam` in
  lean4-explicit-proofs.
